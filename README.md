# 森林資源メッシュ用国土基本図図郭作成プラグイン

<img src="forest_map_sheet_generator/icon.png" width="96" alt="plugin icon">

v0.1.0。作者：Yoichi Wada。
このリポジトリにはQGISプラグイン本体、計算試験、試験用インストールZIPの作成手順を含めます。正式版は GitHub Release の v0.1.0 です。

## このプラグインについて

林野庁『森林情報に関するオープンデータ標準仕様書 Ver2.1（2026年8月版）』に準拠して、森林資源メッシュの作成・公開に必要となる国土基本図図郭と図郭コードを、QGISで生成するプラグインです。林野庁の公式プラグインではなく、同仕様書を原典として図郭の位置・寸法・コードを照合した実装です。

図郭コードと座標範囲の期待値は、仕様書（印刷p.63 参考3図1、p.64 子区画、p.7 図1.4）から実装とは独立に作成し、それと一致することを検証しています。

### 生成できる図郭

|種別|寸法（南北×東西）|コード例|
|---|---|---|
|1:50,000図郭|30,000m×40,000m|04HE|
|森林用4分割（1:50,000図郭の4分割）|15,000m×20,000m|04HE1〜04HE4（北西1・北東2・南西3・南東4）|
|1:5,000図郭|3,000m×4,000m|04HE00（行・列とも北・西から0〜9）|

森林用4分割は、仕様書 図1.4 に基づく区分です。通常の1:25,000図郭とは別物として扱います。

### 操作の流れ

- 範囲の指定は3通り：地図の表示範囲／ポリゴンレイヤ全体または選択地物／図郭コードの直接入力
- 平面直角座標系（JGD2011、1〜19系）の選択は、手動指定（複数系可）のほか、系の適用区域レイヤによる自動判定にも対応します。自動判定では、対象範囲と適用区域が面積を持って重なる系だけを対象とし、点・辺のみの接触は除きます
- 系の適用区域には https://github.com/yo-1/japan-plane-rectangular-cs-zones の公開GeoPackageを使用します
- 生成前に件数プレビューを表示し、実行は利用者が選ぶ形です。既存のファイルやレイヤを無断で上書きしません

### 生成規則

- 図郭は生成先の系の座標系上で完全な長方形として保存し、行政界や適用区域でクリップしません
- 系の境界付近で異なる系の図郭が重なることは許容します。同一系・同一種別・同一コードの重複は除きます
- 適用区域で覆われない部分（海域など）は通知します。最も近い系へ自動で割り当てることはしません

### 出力

GeoPackageに、系・図郭種別ごとのレイヤで出力します（例：grid_z04_50000、grid_z04_5000、grid_z04_forest_quarter）。属性は sheet_code、zone、grid_type、parent_code、epsg と図郭の座標範囲（e_min／e_max／n_min／n_max）です。あわせて、生成に使ったプラグインの版、指定方法、適用区域データの版と出典を、同じGeoPackage内の来歴テーブルに残します。

### 関連プラグイン：森林資源量メッシュ（20m）生成プラグイン

本プラグインの森林用4分割図郭は、森林資源量メッシュの「ファイル単位」です。その中を20m四方に区切ったものが、航空レーザ計測による森林資源解析の成果を集計し、公開する単位になります。

関連プラグイン forest_mesh20m（ https://github.com/yo-1/forest-mesh20m 、v0.4.2・実験版）は、『森林情報に関するオープンデータ標準仕様書 Ver.2.1【航空レーザ森林資源解析データ編】』に沿って、ファイル単位図郭の中を20m格子に区切ります。1図郭あたり75万セルで、各セルに12桁のID（JF20mID、暫定名）と所属するファイル単位図郭（file_zukaku）が付きます。同プラグインの格子は本プラグインの出力と照合済みで、図郭の外周座標と図郭名が全件一致しています。同プラグインが作るのは格子までで、樹高・本数・材積といった属性の集計は対象外です。

### 本プラグインの範囲外・既知の未検証事項

- DEM解析、20mメッシュの生成、森林資源量の集計は行いません。本プラグインは、それらの前段である図郭とコードの生成専用です
- 座標系はJGD2011のみ対応し、JGD2024は初版の対象外です。対象環境はWindows／QGIS 3.44です
- 書込みフェーズでの取消（V14b）は実機で未検証です（候補計算中の取消は確認済み）
- プラグイン管理画面からのZIPインストール（W02）は、確認に使った環境で管理画面が応答停止したため未検証です（ZIPの展開配置による導入と動作は確認済み）
