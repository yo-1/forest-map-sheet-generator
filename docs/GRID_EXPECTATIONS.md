# 図郭計算の独立期待値

実装関数を使わず、GSJの図郭コード解説と仕様の寸法から固定した値を `tests/fixtures/expected_grids.csv` に記録した。

GSJの1:50,000コードは、系番号2桁の後に東距40,000m単位の英字、北距30,000m単位の英字をこの順で付ける。英字は A=0, B=1 … Z=25 である。したがって `04HE` は第4系、東距 `[280000,320000]`、北距 `[120000,150000]` であり、寸法は40km×30kmである。座標は GIS の `(x,y)=(easting,northing)` に統一する。

1:5,000は親図郭を北から南へ行0～9、西から東へ列0～9に分ける。`04HE00` は `[280000,284000]×[147000,150000]`、`04HE99` は `[316000,320000]×[120000,123000]` である。森林用4分割は標準仕様書 図1.4 の指定どおり北西=1、北東=2、南西=3、南東=4で、各20km×15kmである。

点のコード帰属は半開区間 `[min,max)` とする。共有する東・北境界は東・北側の隣接図郭に属する。抽出時は交差面積が `1e-7 m²` より大きいものだけを採用し、辺・角だけの接触を除外する。浮動小数点誤差用にコード判定には `1e-7 m` を使用する。英字範囲外の負座標は、0へ丸めず理由付きで拒否する。

出典：GSJ 図郭コード解説（DATA_SOURCES.md）、森林情報に関するオープンデータ標準仕様書 Ver2.1 図1.4、docs/SPEC.md。
