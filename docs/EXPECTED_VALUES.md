# 独立期待値と境界規則

この表は実装関数から生成しない。固定値は `tests/fixtures/expected_grids.csv` にも同じ根拠・手計算として保存する。

## 根拠と計算

- 1:50,000はGSJ「図郭コード解説」の東西40,000m、南北30,000mの投影座標バンドと、I/Oを除く英字順を用いる。第1英字は東距40kmバンド、第2英字は北距30kmバンドである。
- 例 `04HE` は第4系、`H`=7、`E`=4。従って東距 `[7×40,000, 8×40,000)` = `[280,000, 320,000)`、北距 `[4×30,000, 5×30,000)` = `[120,000, 150,000)`。
- 1:5,000は仕様の30,000m×40,000mを10×10分割する。行は北から南、列は西から東なので `04HE00` は東距 `[280,000,284,000)`、北距 `[147,000,150,000)`。
- 森林用4分割は森林情報に関するオープンデータ標準仕様書 Ver2.1 図1.4、およびSPECの北西1・北東2・南西3・南東4に従う。`04HE1` は `[280,000,300,000)×[135,000,150,000)`、`04HE4` は `[300,000,320,000)×[120,000,135,000)`。

座標はすべて GIS の x=東距、y=北距で表記する。日本の測量表記のX=北距、Y=東距は使わない。

## 境界

図郭は左・下を含み、右・上を含まない半開区間 `[e_min,e_max) × [n_min,n_max)` とする。境界点からコードを求める場合は、北・東の隣接図郭へ帰属する。抽出は正の面積交差のみで、点・辺だけの接触は含めない。丸め誤差は `1e-7 m` 以下だけを格子線にスナップし、負座標の帯番号は数学的floorで求める。

この規則により、1:50,000の右上端 `320000,150000` は `04HE` の範囲外であり、矩形抽出の最大辺がそこで終わる場合は隣接図郭を選ばない。
