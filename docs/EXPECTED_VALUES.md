## 原典に基づく計算

南北行は北からA～T（I/Oを含む）、東西列は西からA～H。英字の順序は南北→東西。原点を中心に北距±300km、東距±160kmを区切る。GISのeasting=測量Y、northing=測量Xとして保存する。

行r、列cの0始まり番号から、e_min=-160000+40000*c、e_max=e_min+40000、n_max=300000-30000*r、n_min=n_max-30000。

## 境界

点の帰属は左・下を含む半開区間[e_min,e_max)×[n_min,n_max)で、格子線上は北・東側へ帰属する。点判定だけは1e-7m以内を格子線へスナップする。最西・最南端は含み、最東・最北端は点判定で範囲外。矩形範囲の最大辺は最東・最北端まで指定可能。

面積抽出にはepsilonを差し引かず、正の交差をすべて採用する。点・辺接触のみは除く。範囲が原典の外へ延びる場合は黙ってクリップせず拒否する。原典範囲外へのコード拡張は未対応。

## 訂正履歴

a0074378の旧期待値は軸順・原点オフセット・I/Oを誤り、04HEを東距280～320km／北距120～150kmとしていた。旧試験成功は原典準拠の証拠ではなく、新しい固定値・負座標試験で再検証する。旧ZIPのWindows確認を修正版へ転用しない。
