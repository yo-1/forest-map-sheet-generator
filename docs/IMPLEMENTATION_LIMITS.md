# rc2候補の取消と来歴（v0.1.0-rc2）

- 計算中は進捗画面の「取消」を押せます。候補照合のループが取消を検知した時点で例外として中止し、GeoPackageには書き込みません。
- 件数確認画面で系の不足・適用区域の未被覆を示します。不足系を近傍系で補完しません。適用区域データ版は利用者の入力を採用し、未入力なら `unknown` を来歴に記録します。
- 件数確認後の書込みも取消できます。同じフォルダの作業用GeoPackageに全レイヤ・来歴を作成し、完了時に出力先へ置き換えます。取消・書込失敗時は作業ファイルを削除し、既存出力は変更しません。新規出力時は出力先を作りません。既存ファイルの複製には追加のディスク容量が必要です。Windowsで出力先を別のアプリが開いて置換を拒否した場合は、閉じて再実行してください。
- 試験用ZIPをビルドすると `_build_info.py` をZIP内部に生成します。Git checkout ではHEADの40文字SHAを埋め込み、checkoutがない場合は `--commit <40文字SHA>` を指定します。どちらも不可能なら `unknown` と記録します。コード自身の変更でcommitが変わるため、このファイルはソースツリーにコミットしません。
- 大量範囲では候補一覧の生成、適用区域の和集合計算、既存GeoPackageの複製、レイヤ確定処理が取消操作に応答するまで時間がかかることがあります。書込み中は地物ごと、系ごと、確定直前に取消を確認します。V14のWindows実機確認は未完了です。

Windows／QGIS 3.44でのV01～V14の実機確認は未実施です。ソース変更後はZIPとSHA256を作り直してください。
