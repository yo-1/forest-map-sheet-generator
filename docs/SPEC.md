# 開発仕様 v0.1.0

正式名称：森林資源メッシュ用国土基本図図郭作成プラグイン。
リポジトリ候補：yo-1/forest-map-sheet-generator（まだ作成していません）。

## 初版の対象

|種別|南北×東西|コード例|
|---|---|---|
|1:50,000|30,000m×40,000m|04HE|
|1:5,000|3,000m×4,000m|04HE00|
|森林用4分割|15,000m×20,000m|04HE1～04HE4|

森林用番号は北西1、北東2、南西3、南東4。1:5,000は北から南の行・西から東の列を0～9で表します。
森林用4分割を通常の1:25,000と呼ばないこと。
1:50,000の英字割当と座標範囲はGSJの解説を参照し、独立した期待値を作成してから実装してください。
日本の測量表記X＝北距、Y＝東距と、GISのx＝東距、y＝北距を混同しないこと。内部変数は easting/northing を推奨します。

## UI

範囲指定：地図の表示範囲／ポリゴンレイヤ全体または選択地物／図郭コード直接入力。
系選択：手動（全国1～19、複数可）／適用区域レイヤによる自動。
図郭種別、出力GeoPackage、生成件数プレビュー、実行・取消を用意。
大量生成前には件数を表示し、利用者が実行を選べること。既存ファイル・レイヤを無断で上書きしないこと。

## 基礎ポリゴンとの接続

基準版候補：japan-plane-rectangular-cs-zones Releases v2026.1 の系別19件版。
初版は外部GeoPackageをQGISに読み込み、適用区域レイヤとして選択します。同梱・自動ダウンロードは初版に含めません。
必須属性ZONEは整数1～19。ZONE_ROMANは表示用、EPSGは整合確認用（必須ではない）。
レイヤの実CRSを座標変換に使用。公開版の実CRSはEPSG:6668、属性EPSGは各系の生成先CRSです。
JGD2011の生成先は1～19系に対応するEPSG:6669～6687。JGD2024対応は初版に含めません。
CRS未設定・ZONE不正・空形状・無効形状・EPSG不整合は原因を表示して自動判定を停止。黙って修復しないこと。
同じZONEの複数地物は許容し、系ごとにまとめて扱います。19系すべて揃わない任意レイヤは警告し、覆われない部分を報告します。

## 抽出・生成規則

対象区域をA、系の適用区域をZとしたとき、自動選択はA∩Zの面積が正の系を対象とします。
その系で必要な図郭はA∩Zと面積を持って重なるもの。点・辺だけの接触は除きます。
手動系選択では適用区域で制限せず、対象Aを使います。
直接コード入力ではコード内の系を使い、適用区域の選別を行いません。
必要に応じ範囲の辺を細分化してCRS変換し、曲線を四隅だけで近似して図郭を取りこぼさないこと。
図郭は生成先CRS上の完全な長方形を保存し、行政界・適用区域でクリップしません。
異なる系の図郭が境界付近で重なることを許容します。同じ系・種別・コードの重複は除きます。
海域など適用区域で覆われない部分は通知します。最近傍の系への自動割当はしません。
浮動小数点誤差の許容値と座標点の境界帰属規則を明記し、固定した期待値で検証してください。

## 出力

GeoPackage内に系・図郭種別ごとのレイヤ：grid_z04_50000、grid_z04_5000、grid_z04_forest_quarter など。
属性：sheet_code（文字列）、zone、grid_type、parent_code、epsg、e_min/e_max/n_min/n_max。
来歴はGeoPackage内の専用非空間テーブルに保存：plugin_version、commit、生成日時、指定方法、適用区域版、レイヤ名、出典URL。
任意データの版は不明を許容します。個人のローカル絶対パスやDrive IDは出力来歴に記録しません。

## 将来の統合方針

森林資源量集計メッシュ作成プラグインとの統合は将来候補です。初版では統合しません。
図郭計算をUI・20mメッシュ計算から独立したモジュールにし、入出力は図郭ポリゴン、コード、系番号、CRSとします。
将来統合する場合も利用者の操作は「図郭作成」と「資源量集計メッシュ作成」の2入口を維持し、設定を一画面に混在させません。
統合判断の条件：操作が増えない、依存関係が過度に増えない、単独機能の試験と保守ができること。
複数モジュールの統合設計を実施する段階ではClaude.aiでの設計検討に引き継ぎます。
