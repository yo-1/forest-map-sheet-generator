# 検証計画 v0.1.0

期待値は実装関数から生成せず、仕様の図・座標原点・手計算から固定します。各期待値に出典と計算過程を付けます。

|ID|対象|合格条件|
|---|---|---|
|V01|1:50,000既知図郭|コード・四隅座標・30km×40kmが一致|
|V02|1:5,000|100枚の順序・寸法・コードが正しく、合計が親に一致|
|V03|森林用4分割|北西1／北東2／南西3／南東4、合計が親に一致|
|V04|全国19系|同じ計算規則、系番号・CRS対応が正しい|
|V05|正負座標・原点付近|切捨てと負数処理によるずれなし|
|V06|コード往復|コード→長方形→中心点→コードで一致|
|V07|不正コード|桁・系・英字・子番号を理由付き拒否|
|V08|図郭の辺と角|接触のみは抽出せず、微小な正面積交差は採用|
|V09|区域境界・複数系|各系のA∩Zから生成、完全長方形、別系の重なりを保持|
|V10|適用区域外|未被覆部分を通知、無断系割当なし|
|V11|座標変換|変換後の曲線も考慮し取りこぼしなし|
|V12|入力レイヤ異常|CRS・ZONE・形状・EPSGの異常が明示される|
|V13|GeoPackage再読込|属性・先頭ゼロ・CRS・四隅・来歴が保持|
|V14|UI・取消・大量生成|取消可能、重複メニューなし、件数確認、無断上書きなし|

辺や角の座標点からコードを求める際の帰属規則は実装前に定義し、V06/V08で固定。
寸法・面積・隙間は各系の投影座標で比較。緯度経度で長方形・距離を判定しません。
計算試験とQGIS結合試験は分け、未導入依存のスキップを未実行として報告します。
実機対象：Windows、QGIS 3.44。対象コミットと使用ZIPのSHA256を記録。
試験記録の列：ID、版、コミット、環境、入力、期待値、実測、結果、証拠、確認日。

初回実装では `.github/workflows/tests.yml` が純Python計算試験とQGIS結合試験を別ジョブとして実行する。QGISがない通常Python環境でのskipは結合試験の成功として扱わない。
