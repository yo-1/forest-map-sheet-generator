# Windows / QGIS 3.44 実機確認手順

この手順は未実行です。[結果テンプレート](WINDOWS_QGIS_344_RESULT_TEMPLATE.md)に対象コミットと実際にインストールしたZIPのSHA256を記録してください。PRを更新したら、最新版のコミットからZIPを作り直して照合します。

1. PRの対象コミットを取得し、リポジトリ直下で `python scripts/build_plugin_zip.py` を実行します。生成された `dist/forest_map_sheet_generator-0.1.0-rc1.zip` のSHA256を、同名の `.sha256` ファイルおよび `CertUtil -hashfile dist\\forest_map_sheet_generator-0.1.0-rc1.zip SHA256` と照合します。
2. Windows版QGIS 3.44の「プラグインを管理とインストール」→「ZIPからインストール」でZIPを導入して有効化します。メニュー「森林資源メッシュ」に起動項目が一つだけ現れることを確認します。
3. メニューからダイアログを開き、「範囲指定＝図郭コード直接入力」で図郭種別を切り替えながら `04HE`（1:50,000）、`04HE00`（1:5,000）、`04HE1`（森林用4分割）を入力します。それぞれ**新規の**出力GeoPackageを指定し、「OK」→件数確認→「はい」で生成します。件数確認の「いいえ」では出力されないことも確認します。現行UIには寸法のプレビュー表示はないため、寸法は出力後の属性と形状で判定します。
4. GeoPackageをQGISに読み込み、`grid_z04_50000` 等のレイヤ名、CRS（4系はEPSG:6672）、`sheet_code`、`zone`、`grid_type`、`parent_code`、`epsg`、境界座標、長方形の寸法（40,000×30,000m、4,000×3,000m、20,000×15,000m）と来歴テーブルを独立期待値と照合します。図郭コードの先頭ゼロも確認します。
5. 同じGeoPackageの同名レイヤへ再出力を試み、無断上書きせず理由が表示されることを確認します。異なる系のレイヤはそれぞれのCRSで保存され、境界付近で重なって見えてよいことを確認します。
6. 「地図の表示範囲」「ポリゴンレイヤ（選択地物を優先）」それぞれで手動系選択を試します。適用区域レイヤを読み込んだ自動系判定では、正面積で交わる系を選び、辺・点の接触だけの系は除きます。未被覆部分の通知、異常な適用区域レイヤ、取消、無断上書きも確認します。
7. [検証計画](VALIDATION_PLAN.md)のV01～V14を結果テンプレートに記入します。各行を成功／失敗／未実行で区別し、入力、独立期待値、実測、証拠を記録してください。実施できなかった項目は理由を書き、成功扱いにしません。
